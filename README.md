# My journey into Backend Engieering , including all learing process like Language netowrk concept

## Projects

- [`simplewm`](simplewm) — a minimal X11 window manager written in Go,
  with a configurable autostart/keybinding system and security features
  (screen lock, idle auto-lock).
- [`redpac`](redpac) — installs this setup's main programs (the `st`
  terminal, `fish` shell, `nyxt` browser, Neovim+LazyVim editor, and the
  `bottom`/`lazydocker`/`slock` devops/security tools) via pacman (Arch
  Linux) or emerge (Gentoo). Includes keybinding cheatsheets for nyxt
  and fish.
- [`i3backup`](i3backup) — backs up an i3 window manager environment
  (config, status bar, compositor, launcher, notifications, X
  resources) into a single restorable tarball.
